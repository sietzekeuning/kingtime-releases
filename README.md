# Kingtime for Mac · releases

Downloads and the update feed of Kingtime for Mac, the menu bar app of [Kingtime](https://kingtime.nl).

- Download the newest version at **https://kingtime.nl/download/mac**.
- Installed copies update themselves through `appcast.xml` in this repository (served via https://kingtime.nl/download/appcast.xml).

Every release is signed with a Developer ID, notarised by Apple and signed for Sparkle.
